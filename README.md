# Froggy

Skapa en webbaserad mobilapp med html, css och javascript baserat på denna design. <br>
1: Listans syfte är att synliggöra hur lång tid olika saker tar så att listan är möjlig att genomföra med den tid som finns. <br>
2: Varje task i listan kan ha sub-tasks. <br>
3: När man gör en task uppskattar man hur lång tid den kommer ta, detta visas sedan med hur stort task-kortet är i list-vyn. <br>
4: I list-vyn kan man flytta task-korten upp och ner i listan för att ändra ordningen. Man kan även dra i botten av korten för att göra dem större eller mindre på höjden. Detta påverkar hur lång tid en task förväntas ta och styrs i 5-minuters inkrement. <br>
5: När en sub-task checkas av läggs den i botten av subtasksen för den main-tasken <br>
6: Genom att flytta mellan olika dagar eller dra över tasks till andra dagar kan man planera även nästkommande dagar på förhand. <br>
7: Om en main-task inte är klar i tid blir froggy ledsen. Se till att följa din plan hör att hålla Froggy glad! <br>
